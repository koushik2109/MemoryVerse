## 1. Overview and Architecture

This package provides a completely self-contained, independent, raw-data-based recomputation of all experimental results, confidence intervals, hypothesis tests, equivalence bounds, conformal risk controls, and inter-rater agreement statistics reported in the MemoryVerse manuscript.

### Strict Scientific Safeguards
1. **Zero Hard-Coded Metrics:** No experimental mean, difference, standard error, or p-value is hard-coded.
2. **First-Principles Derivation:** Every reported metric is derived dynamically from raw queries, OCR transcriptions, and per-query similarity ranks stored in `raw_data/`.
3. **Transparent Evidence Gating:** Where raw query-level data was not persisted in original historical experiments (e.g. RAMP H1/H2, FUNSD Dense BGE), comparisons are explicitly labeled `NOT_REPRODUCIBLE` without substituting fabricated numbers.
4. **Independent Validation:** An isolated verification script (`scripts/independent_validation.py`) validates results against raw observations without importing pipeline code.

## 3. Reproduction Instructions

### Prerequisites
- Python $\ge$ 3.10
- Packages: `numpy`, `pandas`, `scipy`
- TeX Engine (for manuscript compilation): `tectonic` or `pdflatex`

```bash
# Optional: create a clean virtual environment
python3 -m venv .venv
source .venv/bin/activate
pip install numpy pandas scipy
```

### Step 1: Run Zero-Base Recomputation Pipeline
Executes all 6 experimental families, computes 10,000 cluster/query bootstraps, 100,000 permutation tests, Holm-Bonferroni step-down corrections, TOST equivalence tests, RCPS split evaluations, and human agreement kappas directly from raw data:

```bash
python scripts/recompute_verified_results.py
```
*Expected runtime:* $\sim 35$--$40$ seconds.

### Step 2: Run Isolated Independent Validation Harness
Independently verifies headline metrics without importing pipeline code and asserts numerical tolerances $< 10^{-4}$:

```bash
python scripts/independent_validation.py
```
*Expected output:* `ALL INDEPENDENT CHECKS PASSED WITH ZERO TOLERANCE VIOLATIONS.`

### Step 3: Run Automated Quality Gates
Runs static AST checks, manifest verification, CI bounding checks, Holm monotonicity, TOST decision rules, zero-variance handling, and historical projection segregation:

```bash
python scripts/automated_quality_gates.py
```
*Expected output:* `ALL 7 SCIENTIFIC QUALITY GATES PASSED.`

### Step 4: Recompile Manuscript
Verifies that the camera-ready PDF compiles cleanly and conforms strictly to the 15.0-page limit:

```bash
cd manuscript
tectonic main.tex
# On macOS:
mdls -name kMDItemNumberOfPages main.pdf
# Expected: kMDItemNumberOfPages = 15
```

## 4. Key Verified Experimental Results

1. **Family 1 (Sparse OCR):** Under real Apple Vision OCR, Character 3–5g BM25 achieves MRR **0.9436** [95% CI: 0.919, 0.965], dominating Word BM25 (0.8371, diff $+0.1065$, $p < 10^{-4}$). Under degraded optical blur, Character BM25 remains robust at **0.8248** [0.784, 0.864] vs Word BM25 (0.6972, diff $+0.1276$, $p < 10^{-4}$).
2. **Family 2 (DocVQA):** Document-native ColQwen2 achieves live measured MRR **0.5497** [0.511, 0.589] (Hit@10 = 0.6860), significantly outperforming text proxies ($\le 0.3507$, diff $+0.2440$, $p < 10^{-4}$). SigLIP achieves MRR **0.1327** [0.107, 0.161].
3. **Family 3 (MS-COCO):** SigLIP Base Patch16 achieves native visual MRR **0.6071** [0.583, 0.632] (Hit@10 = 0.8670), outperforming CLIP (0.4709, diff $+0.1362$, $p < 10^{-4}$) and baseline captioning (0.3695, diff $+0.2376$, $p < 10^{-4}$). SigLIP is statistically equivalent to 4-ref human multi-captioning at margin $\Delta = 0.05$ ($p_{\text{TOST}} = 0.00018 < 0.05$).
4. **Family 6 (Multi-Hop):** On hard 2-hop queries ($N=50$), rule-based extractive PRF matches generative LLM bridging at Hit@10 **0.6400** (32/50), significantly outperforming single-hop BM25 (0.4800, exact McNemar $b=9, c=1, p=0.0215$). On the pooled suite ($N=100$), both achieve Hit@10 **0.8200** with formal TOST equivalence ($p_{\text{TOST}} = 0.0073 < 0.01$).
5. **RCPS Conformal Risk Control:** Expected test miss risk is bounded at **0.0491** at a 78.4% escalation rate (21.6% compute savings). Realized split coverage is **82.0%** across 200 resampled partitions. Conditional risk reaches **0.0627** on entity rewrites, confirming that marginal calibration does not guarantee conditional risk control.
6. **Human Audit Agreement:** Photo-album responses ($N=60$) show 100% agreement ($P_o=1.0, P_e=1.0$), with Cohen's kappa mathematically undefined (`UNDEFINED (Zero Variance)`). Pooled queries ($N=110$) exhibit high inter-rater reliability: Faithfulness $\kappa = 0.8716$, Relevance $\kappa = 0.8926$, Correctness $\kappa = 0.9451$.
