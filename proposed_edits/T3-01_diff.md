# Proposed Edit Diff for T3-01: Controlled Test of Query-Formulation Claim

## Description
Controlled evaluation holding information content constant (company + total + date) across five syntactic formulations (verbatim snippet, keyword bag, declarative sentence, interrogative question, conversational imperative) on $N=306$ held-out probes and 813 test corpus items under $B=100,000$ paired permutations.
Data source: `results/gapfill_v1/T3-01/statistical_tests.csv` and `query_formulation_summary.csv`.

## Causal Policy Guidance
**Recommendation:** The manuscript must NOT employ causal language attributing dense bi-encoder failure to syntactic question format. Paired permutation tests show no statistically significant difference between keyword bags and interrogative questions ($p = 0.3369$ for BGE, $p = 0.0562$ for MiniLM on Real OCR), and declarative sentences match interrogative questions ($p = 0.3481$ for BGE, $p = 0.9261$ for MiniLM). Instead, the causal driver of dense recovery is **entity co-specification mass** (single entity snippet to multi-entity anchors: BGE MRR $+0.2126$, $p < 10^{-5}$), while syntactic phrasing is purely observational.
