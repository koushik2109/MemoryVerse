# Empirical Decision Guide: Text Proxies vs. Native-Visual Representations

Across multimodal retrieval benchmarks spanning physical administrative documents and natural photography, system architecture must be selected according to modality and query intent rather than nominal OCR quality. For physical scanned documents, character 3–5gram BM25 is the optimal baseline: it achieves MRR = 0.9443 on clean OCR, absorbs optical blur degradation (MRR = 0.8248), and dominates answerable question lookups (MRR = 0.9558) at 0.87 ms latency, while document-native visual retrieval (ColQwen2-v1.0) provides a statistically detectable advantage only under semantic light paraphrasing (+0.0577 MRR over hybrid fusion, p = 0.0084). Conversely, for natural scene photography, machine caption proxies fundamentally fail: native visual representations (SigLIP Base Patch16 MRR = 0.6071, CLIP ViT-B/32 MRR = 0.4709) decisively outperform the highest-capacity caption proxies (Dense BGE BLIP-2 MRR = 0.4185; p < 1e-4), establishing that direct pixel embeddings are non-negotiable for natural visual semantics.
