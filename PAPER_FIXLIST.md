## Summary of Manuscript Audit Findings

A forensic review of `IEEE_Paper_MemoryVerse.tex` identified several critical vulnerabilities that would immediately disqualify the paper under scrutiny:
1. **Contradicted & Fabricated TOST Artifact:** Section V-G reported an exact Two One-Sided Tests (TOST) equivalence ($+0.0000$ [$+0.0000, +0.0000$], $p = 0.00000$) between Grounded Extractive Bridging and Generative LLM Bridging. This was produced by a script running TOST on identical arrays created with `np.copy()`. Exact paired case analysis reveals that multi-hop LLM bridging adds zero statistically detectable retrieval value over single-stage hybrid retrieval (+1 net hit / 50; exact McNemar $p = 1.0000$) or single-stage dense retrieval (identical 32/50 hits).
2. **Unachievable Conformal Guarantee Claim:** Section V-E and the Abstract claimed that split conformal cascade calibration "guarantees non-escalated miss rates $\le 0.05$". Across 200 random cluster-stratified 50/50 splits, the empirical test miss rate exceeds 0.05 in ~63% of splits (mean test miss rate 0.0579, empirical coverage only 36.5%--37.0%). Furthermore, an equal-escalation fixed margin threshold ($\tau = 0.380$) achieves identical MRR ($0.3526$ vs $0.3527$) and latency ($76.3$ ms).
3. **Reconciled Router Claim (H2 Killed):** Section V-D claimed that learned query routing improves MRR by $+0.1938$ ($p < 0.001$). This was an artifact of comparing the router to an unnormalized strawman baseline (All-Stream RRF, MRR = $0.1827$). When compared to the true baseline (Tuned Hybrid, MRR = $0.3694$), the router provides a marginal lift of only $+0.0071$ under synthetic noise ($p_{\text{Holm}} = 0.042$) and zero lift under real Apple Vision OCR ($p_{\text{Holm}} = 1.0$).
4. **Inflated Legacy CER/WER:** Section V-A reported Clean OCR CER = $0.4519$ and WER = $0.6503$, and Degraded OCR CER = $0.5218$ and WER = $0.7561$. These numbers were severely inflated by SROIE comma-truncation and unnormalized vertical line transpositions. Correct normalized line-aligned metrics are: Clean OCR CER = $0.1387$, WER = $0.2165$; Degraded Blur CER = $0.3086$, WER = $0.4595$.
5. **Chance Heavy Paraphrase Benchmark:** Section V-B reported heavy paraphrase MRR of $0.008$ to $0.009$, which matched uniform random guessing ($0.00895$) due to aggressive token stripping during probe generation. Replacing these with answerable factual questions generated by LLM ($T=0.0$) yields a valid evaluation: BM25 MRR = $0.9014$, MiniLM = $0.2837$, BGE-base = $0.5128$.
6. **Stale Private 55-Probe Data in Introduction:** Lines 66--68 in Section I cited numbers from a private 55-probe dataset (e.g., MRR collapsing from 0.8527 to 0.3691 at 40% noise; BM25+Clean vision reaching 0.9450; 14.55% escalation rate) that do not exist on the public benchmark.
